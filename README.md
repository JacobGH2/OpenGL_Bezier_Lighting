# Usage

## Controls
### Bézier surface manipulation
```r``` - switch active control point, current shown in red

```d```: -y | ```f```: +y | ```arrow keys```: movement in x-z plane

### Bézier surface appearance

```u``` - wireframe/polygon surface

```b``` - back face culling on/off

```t``` - show solid color/texture map

```q``` and ```w``` - rotate scene



### Lighting
```l``` - lighting on/off

```k``` - flat/smooth shading

```a```, ```s``` - decrease/increase specular exponent

```n```, ```m``` - decrease/increase diffuse coefficient

```z```, ```x``` - light source movement


### Other

```j``` - close program
